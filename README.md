# Eric Wong

I build software that turns messy real-world data and AI capabilities into
clear, usable products. Most of my work combines a TypeScript frontend with a
Python backend and tests around the parts that affect real data or user state.

## Selected work

### [Macau Traffic Intelligence](https://github.com/Eric0417/macau-traffic-intelligence)

A map-first public transport dashboard for Macau. It combines road congestion,
bridge travel times, live bus positions, traffic cameras, parking, weather,
border information, and the LRT network in one interface.

`Next.js` `TypeScript` `MapLibre GL` `Zod` `Docker`

[Live app](https://macau-traffic-intelligence.onrender.com) |
[Source](https://github.com/Eric0417/macau-traffic-intelligence)

### [Mathematics Learning Platform](https://github.com/Eric0417/fatmathfat)

A Traditional Chinese learning platform with interactive set and coordinate
geometry tools, practice, progress tracking, Email OTP login, and an AI tutor.

`React` `TypeScript` `FastAPI` `PostgreSQL`

[Source](https://github.com/Eric0417/fatmathfat)

### [IELTS Practice](https://github.com/Eric0417/ielts-practice)

A full-stack practice and grading platform for IELTS reading, listening, and
writing, including AI-assisted writing feedback and attempt history.

`React` `FastAPI` `PostgreSQL` `JWT`

[Live app](https://ielts-system-fat.onrender.com) |
[Source](https://github.com/Eric0417/ielts-practice)

### [SnapStrip](https://github.com/Eric0417/snapstrip-fat)

A local-first four-frame photo booth. Photos are composed and processed in the
browser, with no image upload required for the core editing flow.

`React` `TypeScript` `Vite` `Playwright`

[Live app](https://snapstrip-fat.onrender.com) |
[Source](https://github.com/Eric0417/snapstrip-fat)
